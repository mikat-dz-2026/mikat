طريقة النشر على GitHub Pages (بدون كتابة أي كود)

أولًا: النشر لأول مرة
1) أنشئ حسابًا على github.com ثم New repository، واجعله Public، ثم Create.
2) اضغط "uploading an existing file" واسحب كل ملفات مجلد site (الملفات نفسها لا المجلد)، ثم Commit changes.
3) Settings ثم Pages: Deploy from a branch، الفرع main، المجلد /(root)، ثم Save.
4) رابط التطبيق: https://اسم-حسابك.github.io/اسم-المستودع/
5) رابط لوحة التحكم: نفس الرابط وبعده /admin.html

ثانيًا: استعمال لوحة التحكم (admin.html)
- أكواد التفعيل: ولّد أكوادًا، بعها، ثم نزّل codes.json وارفعه. وحمّل "نسخة الأكواد" واحتفظ بها عندك ولا ترفعها.
- نماذج الخطب: مكتبة الخطب فيها الآن مسودتان فقط. اكتب نموذجيك في لوحة التحكم (نماذج الخطب) ونزّل starters.json وارفعه فيحلان محل المسودتين.
- مكتبة الكتب: books.json جاهز فيه 22 كتابًا (تفسير وحديث وفقه) بلا روابط. افتح تبويب «مكتبة الكتب» في اللوحة، ضع رابط كل كتاب، نزّل books.json وارفعه.
- موضوع الجمعة / التعليمات / المجموعات / الروابط: املأ النموذج ثم نزّل الملف وارفعه.
- الرفع: في المستودع Add file ثم Upload files، واسحب الملف، فيستبدل القديم تلقائيًا.

ملاحظات:
- لوحة التحكم لا تغيّر الموقع بنفسها، بل تجهّز لك الملفات فقط، فلا يستطيع أحد غيرك النشر.
- الأكواد المولّدة تُحفظ في متصفح جهازك، فنزّل نسخة احتياطية منها دائمًا.
- ملف "اكواد_التفعيل_سرية.txt" لا ترفعه أبدًا.
- عند تعديل index.html غيّر الرقم في sw.js من mikat-v1 إلى mikat-v2 ليصل التحديث للمستخدمين.
